Just send events

No SDK required. No complicated setup. NewStream works with simple HTTP requests.

POST /sessions/demo/events
curl -X POST https://newstream-production.up.railway.app/sessions/demo/events \

-H "Content-Type: application/json" \
-H "x-api-key: YOUR_API_KEY" \

-d '{
  "type":"token",
  "text":"hello world",
  "model":"gpt-4"
}'
