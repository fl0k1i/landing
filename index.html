the analogy

Two primitives.
One for rest, one for motion.

Amazon S3
Files at rest
Objects. Buckets. Put, get, delete. S3 gave the world a universal primitive for storing static data — images, documents, backups, archives.
files objects static put / get at rest
vs
NewStream
Data in motion
Streams. Sessions. Append, read, replay. NewStream gives you a universal primitive for moving data — AI events, agent traces, sensor readings, anything that flows over time.
streams events ordered append / replay in motion
design principles

Four properties
that matter.

01
Ordered
Every event has a sequence number. Order is guaranteed. You always know what happened before what.
02
Durable
Append once, read forever. Nothing expires. Every session from day one is replayable on demand.
03
Live
Tail any stream in real time. Watch sessions as they happen. Sub-second latency from write to read.
04
Simple
Three endpoints. One HTTP POST to write. One GET to read. No SDK required. Any language, any stack.
